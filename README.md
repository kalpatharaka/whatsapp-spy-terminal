Professional WhatsApp Monitoring Tool with Hacker-style Dashboard. Optimized for restricted networks (UAE/Middle East).

## ⚡ Quick Start for Beginners (ලෙහෙසියෙන් පණගන්වමු)

1. **Clone the Repo:**
   ```bash
   git clone https://github.com/kalpatharaka/whatsapp-spy-terminal.git
   ```

2. **Enter Folder:**
   ```bash
   cd whatsapp-spy-terminal
   ```

3. **Install Tools:**
   ```bash
   npm install
   ```

4. **Start Spying:**
   ```bash
   node index.js
   ```
